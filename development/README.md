# Development source, not an installable plugin

This directory contains the newly written EEGLAB entry points, settings dialog,
progress display, numerical compatibility helpers, and a local test harness for
CleanLine GPT-6 Optimized. The Original and Optimized CleanLine V2 computation
packages are intentionally absent while their redistribution terms are reviewed.
The test harness therefore requires the complete local prototype and the
original CleanLine 2.00 installation. Do not install this directory as a plugin.

The complete prototype and its ZIP remain local. The public repository's GPL v3
`LICENSE` does not establish the license of third-party CleanLine V2 files.
See [`../docs/LICENSING_AUDIT.md`](../docs/LICENSING_AUDIT.md).
